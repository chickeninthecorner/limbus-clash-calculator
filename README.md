# Limbus Clash Calculator

This tool is used to calculate the win rate, tie rate, and lose rate of a clash in Limbus Company.

Access it [here](https://luventiuswidjaya.github.io/limbus-clash-calculator/).

This project was originally built with Python and [Pyscript](https://github.com/pyscript/pyscript). AI was used in translating this project to purely rely on Javascript, C++ and HTML (as well as [Emscripten](https://github.com/emscripten-core/emscripten)) to significantly improve performance. A Python branch (to view the logic) is available.

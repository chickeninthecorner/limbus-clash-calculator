# Limbus Clash Calculator

This tool is used to calculate the win rates, tie rates, and lose rates of a clash in Limbus Company.

Access it [here](https://luventiuswidjaya.github.io/limbus-clash-calculator/).

This project was originally built with Python and [Pyscript](https://github.com/pyscript/pyscript). AI was used in translating this project to convert Python to C++ and Javacript (also using [Emscripten](https://github.com/emscripten-core/emscripten)) to significantly improve performance.
